A Jenkins pipeline that tests a Node.js app with Jest, builds a Docker image and deploys it to AWS EC2 automatically on every commit to GitHub.

What I built
  • Declarative Jenkinsfile with Install, Test, Docker Build and Deploy stages.
  • Dockerfile on node:18-alpine with a non-root user, a health check and build-number image tags for rollback.
  • Source-IP Security Group rules for SSH and Jenkins.
What broke, and the fix
  • The pipeline kept running an old script because the job was set to "Pipeline script". Switching to "Pipeline script from SCM" fixed it.
  • npm ci failed without a lock file, so I committed package-lock.json.
  • A manually started container held port 3001, so the pipeline now owns the container.
