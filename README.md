# MD Farhan Kalim — Cloud Engineer Portfolio

🔗 **Live:** [mcadefarhan.github.io](https://mcadefarhan.github.io)

An interactive, single-page portfolio built as a live "ops console" — no frameworks, no build step, just HTML/CSS/JS.

## Features

- 🖥️ Typing terminal hero (`whoami`, `status`, `stack --top`)
- 🌐 Animated network canvas background that reacts to the cursor
- 🧩 Click-to-inspect architecture diagram (App / Compute / Data tier)
- 📊 Skill meters that animate in on scroll
- 📦 Projects shown as expandable deploy logs
- 🕒 Experience shown as a clickable git-log timeline
- ⌨️ Working command terminal in Contact — type `email`, `resume`, `github`, etc.
- ⌘K command palette — press `Ctrl/Cmd + K` to jump anywhere on the page
- ♿ Respects `prefers-reduced-motion`, fully responsive

## Tech Stack

Plain HTML, CSS, and vanilla JavaScript. No dependencies, no build tools — just open `index.html` in a browser.

## Run Locally

```bash
git clone https://github.com/Mcadefarhan/mcadefarhan.github.io.git
cd mcadefarhan.github.io
# open index.html in your browser, or serve it:
python3 -m http.server 8000
```

## Deploy

This repo is already named `mcadefarhan.github.io`, so GitHub Pages serves it automatically at
**https://mcadefarhan.github.io** — no extra configuration needed. Just keep `index.html` and
`resume.pdf` in the root of the repo.
